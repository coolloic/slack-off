# sample-weekly-report

A fictional, tiny project used by Slack Off's "Try on a sample ticket". It computes the weekly orders report shown on
a report page.

- `src/data/orders.js` — in-memory sample orders.
- `src/report/weekly.js` — groups orders by ISO week.
- `src/report/format.js` — formats weeks and money for display.
- `src/report/index.js` — the report page's data handler.
