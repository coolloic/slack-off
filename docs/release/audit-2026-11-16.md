## Findings

- **CI is red.** GitHub CI on macOS runners fails 3 server sandbox tests. A fix is in progress on `fix/ci-macos-sandbox-tests`. `check` is a required status check, so pull requests stay blocked until it is green.
- **A clone in a temporary folder breaks the sandbox self-check (documentation gap).** If the repository is cloned under `/private/tmp` (or `$TMPDIR`), Settings shows the sandbox self-check as *failed*. Sandboxed code can write there, so a checkout in that location cannot be read-only to it. The same server, started from a normal checkout, reports `ok`. The phase-4 notes document this for `pnpm test`, but README and docs/install.md do not warn users. Suggested fix: one line in install.md §3 (clone outside temporary folders).
- **Dependabot has already opened 7 branches** on the public repository. They are expected, and not private.
