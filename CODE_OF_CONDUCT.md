# Code of conduct

Slack Off follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). In short: be welcoming and respectful, give and take feedback on the work rather than the person, and assume good faith. Harassment, insults, sexualised language or imagery, and publishing someone's private information are not acceptable, anywhere the project is discussed.

## Reporting

If someone's behaviour in this project's issues, pull requests or discussions is unacceptable, report it privately to the maintainers through GitHub: use **Report content** on the comment, issue or pull request (the menu on each one), or [open a private report](https://github.com/coolloic/slack-off/security/advisories/new) and say it is a conduct report. Every report is reviewed and kept confidential.

The maintainers may remove, edit or reject comments, commits, code and issues that break this code of conduct, and may ban a contributor temporarily or permanently, following the Contributor Covenant's enforcement guidelines.
